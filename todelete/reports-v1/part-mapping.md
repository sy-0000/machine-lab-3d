# 16K20 真實模型零件對照與檢查紀錄

模型：lathe_16k20_dark_green_no_backboard.glb。GLB 含 182 筆節點、172 筆網格；目前場景可達 180 個節點、170 個 Mesh。

所有下列 Pivot 都是 **原始 GLB 世界座標**（X 沿床身、Y 向上、Z 朝前），建立群組後再將整台模型視覺置中。畫面檢查器顯示的是置中後的當前世界座標。軸符號是 Pivot 的局部軸，建立時與原模型世界軸對齊。

| 功能 | 輪身 GLB 來源 | 握把 GLB 來源 | 旋轉軸 | Pivot (X, Y, Z) | 速度 rad/s |
|---|---|---|---|---|---|
| 縱向進給手輪 | Object_117::wheelBody | Object_117::gripRim | Z | (0.0791843, 0.4864774, 0.349) | 2.4 |
| 橫向進給手輪 | Object_107 | Object_109 | Z | (0.0791951, 0.6833978, 0.397) | 2.4 |

`::` 後綴是從指定真實 Mesh 原始三角形建立的索引分區，不是 GLB 原生節點名稱，也不是新增的示意幾何。原始 Mesh 的每個三角形恰好分配一次，外觀與頂點不變。

- Object_117：外緣半徑 > 0.053 的原始三角形為整合式握持環。wheelBody 3198 三角形；gripRim 5250 三角形。
- Object_145：原始三角形中心 X > 0.418 為向外凸出的整合握把。wheelBody 1024 三角形；grip 190 三角形。
- Object_78：原始三角形中心 X > -0.335 為夾头盤，其餘為穿過主軸箱的軸。shaft 107 三角形；chuckBody 3441 三角形。

主軸與夾具：`Object_78::shaft` → `SpindlePivot`；`Object_78::chuckBody` 和 `Object_80`（三個夾爪）→ `ChuckAssembly` → `SpindlePivot`。`WorkpieceMount` 位於 (-0.20274, 0.8525885, -0.0216612)，是 ChuckAssembly 的子節點。若裝上示範工件，也只掛在此處。

啟動拉桿：Object_12（桿）和 Object_38（球形握把），獨立 StartLeverPivot = (-0.4023504, 0.3522738, 0.3674505)，Z 軸，停止 0 rad、啟動 -0.65 rad。Object_10 固定支座不動。0.3 秒切換到 RUN 後才允許主軸加速，停止以 900 RPM/s 減速，保留夾頭停止角度。

固定件包括 Object_22 主軸箱、Object_4 下方機箱、Object_14 床身、Object_193 夾頭防護罩、Object_10 拉桿支座、未列入對照表的機身、引擎與資訊板。不会以位置距離把鄰近機件加入旋轉群組。

## 外觀證據與仍需人工確認

- [整體](full.png)、[縱向輪](carriage.png)、[橫向輪](cross.png)、[側向調節鈕](height.png)、[尾座輪](tail.png)、[主軸與夾爪](spindle.png)、[拉桿](lever.png) 為載入本次真實 GLB 後隔離部件截圖。
- 縱向進給手輪：Object_117 無獨立凸出握把；外緣握持面與輪身依原始三角形分區，未新增握把。
- 橫向進給手輪：實際輪面在 XY 平面，因此使用 Z 軸；Object_107 包含與輪身連成一體的握把桿，Object_109 是末端球形握把。
- 高度調整手輪：側向調節旋鈕的外觀已確認；高度連動是教學配置，原模型沒有機構語意，需實機教師確認。Object_143 支座保持固定。
- 主軸啟動拉桿：Object_10 為固定支座；此拉桿依位置與外觀指定為啟停教學控制，須人工確認實機用途。
- 高度連動只升降 Object_149、Object_150、Object_152、Object_154、Object_156、Object_157 的刀座組合；不是宣稱原機械存在此升降傳動。原檔沒有明確的切削刃語意，因此安全距離採完整刀座組合的保守包圍盒。
- 從原檔 geometry 可確認輪面、握把與支點，但實機功能、方向、行程、控制拉桿用途仍需教師核對。未改寫原始 GLB，未自動重新切割實體造型。
- 新檔案未提供來源連結／授權，頁尾不沿用上一個 Oleg 模型的署名；授權資料需使用者補齊。
