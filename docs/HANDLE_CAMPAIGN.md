# 槌柄 Vertical Slice

入口：Levels → 開始／繼續槌柄 Campaign（`#/campaign/handle`）；舊正式 Level 1 連結亦進入同一流程。自由 `#/lathe` 的工件存檔不變。

四關：基礎端面與外徑操作 → 100 mm 錐度 → 端部 1×45° 倒角 → 壓花／螺紋製程草案。
L1 不再要求 Ø16.3 等徑區；240 是成品名義總長。L2 使用圖面 Ø16.3／Ø9.3，工具實際 X/Z 斜向進給形成錐面。L3 端段 20 的軸向關係沿用圖面，但端段直徑及螺紋未知，不擅自車成 Ø9.3。SR9 位於目前夾持區，需要後續重新裝夾，保持未加工，沒有假外觀。L4 只有有版本的 feature 定義與量測入口，不生成未知壓花／螺紋。

## 操作與尺寸驗收分開

`completedLevels` 表示已記錄教學操作，不是圖面驗收通過。缺少正式公差時表格顯示 nominal／actual／error／draft，允許保留實際誤差繼續後續教學，但不顯示合格。L4 的未知加工不會自動完成；此版本不能宣称整支槌柄已完全完工。
每關仍需真實裝夾、中心高、主軸、外圓接觸/X 設零、端面接觸/Z 設零、實切與停機檢查。L2 必須有覆蓋整個錐段的斜向減料歷史；只切一小段不算完成操作。尺寸量測另從每一格 geometry 計算，不用歷史或輸入值代替幾何。

## 最短操作參考

1. 開始操作；依十步流程對刀。外圓 Ø20 接觸設 X0、毛胚自由面設 Z0。
2. L1：外圓外退刀 X4，端面模式，每次 Z 向內不超過 2 mm，X 進至 −20 掃過中心，再退 X4；重複至名義長 240（原端面零點下 Z−60）。做一段保留餘量的外徑減料。停機、檢查、保存實際工件 → 下一關。不會自動削短。
3. L2：開始／繼續操作，重新對刀。教學裝夾明確選擇圖面左端在實際自由面、圖面 +d 對應實體 −Z。若實際長 240，錐段實體 Z120–220；自由面 Z0 時工件座標 −120 至 −20。若在未切 Ø20 表面設 X0，大端進給為 X−3.7，小端 X−10.7。先退刀定位，靠大端，再以 X/Z 聯動輸入小端終點；亦可分多次聯動。輸入值是刀尖路徑，不是指定結果。若上一關實際長不同，畫面提供實際對應範圍。
4. L3：自由端最後 1 mm 的實際輪廓作倒角；從端面前 1 mm 的外圓處，向端面同時減少 1 mm 半徑（X 直徑減少 2 mm）。以自己的工件零點換算。停機檢查並繼續。
5. L4：查看待確認製程並保留存檔；不可宣稱壓花、螺紋、SR9 已加工完成。

## 保存／Retry

`machine-lab.campaign.handle.v1` 保存 version、specVersion、currentLevel、completedLevels、immutable revision 工件副本、量測及當前 working 工件。每個加工／關卡更新保存，Demo 期間暫停保存。下一關使用上一關實際輸出 clone，絕不由目標重新生成。Retry 恢復本關 input revision；只有 L1 恢復 Ø20×300。重載後按開始／繼續裝回 working geometry，重新建立對刀基準；不自動開主軸。未知版本或損壞存檔報錯，不偷偷重設進度。儲存失敗顯示錯誤。

## 共用切削與 Demo

`machining.line {xDiameterMm,zMm}` 原子驗證兩軸行程後移動真實刀尖，交由現有 cutRevolvedProfile 計算整條連線的 swept minimum，不建立第二個切削器。profile resolution 仍為 0.5 mm，量測同時檢查每格兩端，誠實顯示階梯偏差，沒有假造粗糙度或隱含公差。
Demo 使用本關 input clone，只發 MachineSession 命令；鎖玩家輸入，沿唯一 host clock 的 update 推進。可暫停／重播／跳過。結束恢復玩家幾何、工件零點、刀尖位置與主軸設定；不寫 checkpoint。L1 demo 的 Ø19.8 是明示的保留餘量練習路徑，不是新圖面尺寸。L4 demo 只展示啟停與檢查流程，不模擬不存在的製程。
