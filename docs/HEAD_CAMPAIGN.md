# 槌頭製作流程

入口：加工關卡 →「開始／繼續槌頭 Campaign」，網址 `#/campaign/head`。

四關：基準面／基本尺寸 → 外形／斜面／倒角 → Ø8.5 底孔 → M10。
每關先「開始／繼續槌頭操作」，裝上本關 working copy 及對應刀具。
停機「檢查槌頭尺寸」後，可記錄已做的實切並保存進入下一關；此按鈕不是尺寸驗收合格。
未知公差和未明製程會保持 draft。最後保存實際 tapped-hole，但不宣稱已可組裝驗收。

## 工件與座標

使用者已確認毛胚寬×高×長=20×20×90；基本尺寸=18.5×18.5×86 mm。
圖面左端為 X datum，X 向右，Y 沿毛胚寬度，Z 自底面向上。
工件網格座標永久跟隨原毛胚，不因換機台或移除左端而重新編號；孔距左端量測使用 `hole.xMm − actualBounds.minX`。
孔 Y、孔深／通孔、牙深與正式公差仍 unknown。

實際刀尖在移動工件 local frame 內取樣；Adapter 才轉換 mm/world。
新增程序刀具以明確 axialCuttingEdge 定義刀尖，並校正到 v1 真正 spindle pivot 軸線，不修改 GLB 或舊刀具。
銑床三軸從既有機構實際位移取得方向；鑽床只有套筒垂直進給。鑽床的 X/Y 需停機重新裝夾定位，不偽裝成鑽床 CNC 軸。
裝夾使用 5 mm 刀尖淨空的教學 fixture setup；這是擺放設定，不是圖面尺寸或實機操作參數。

## 實際加工

0.5 mm XY 網格保存每一格實際剩餘高度（Z 為連續 mm），支援頂面、側面切除與 2.5D 斜面／輪廓。
這不是完整實體布林：暫不支援底面翻面或倒扣。刀具圓形 footprint 經掃掠才降低高度，永不增加材料。
3D 顯示相同網格；孔依保存的孔徑、位置、entryZ/depth 挖除網格，高度與孔狀態 reload 後不變。
顯示孔緣有 0.5 mm 離散誤差，孔名義直徑來自實際鑽具直徑，不能用網格畫面當精密公差證據。
沒有粗糙度、螺牙 mesh 或假造 Ra。

平面操作示例（刀具 Ø8，半徑 4；下列是刀尖座標，不是直接修改尺寸）：

1. 開主軸，先在 Z25 淨空移到 X0/Y4；降至 Z18.5，沿 X 掃至 X90。
2. 於 Y10、Y16 重複 X0–90 的掃掠，將頂面銑至 18.5。
3. 退至 Z25，再移到 X−4/Y22.5；降 Z0，沿 X 掃至 X94，切除 Y18.5 以外材料。
4. 退至 Z25，移到 X90/Y−4；降 Z0，沿 Y 掃至 Y24，切除 X86 以外材料。
5. 停機檢查。進入外形關後可聯動 X/Z 切斜面，過切保留。

外形關保存 confirmed 左 1.5×45°／右 3×45°／R1.5，但 spec 尚未定義各視圖到裝夾面的完整對應，因此這些項目沒有冒充完成量測；需補 datum／輪廓規格後才驗收。

鑽削練習：停機定位 X40/Y10（Y10 僅玩家練習選擇，非圖面 confirmed）→ 開主軸 → Z21 → Z15 → 退 Z25 → 停機檢查。
鑽孔需跨過實際表面向下進給，空切、停機、橫拖或直接跳入內部不產生新孔。
進 M10 關，停機定位到實際底孔位置，開主軸再向下進給；只有 Ø8.5 有效底孔可保存 M10/sourceHole/tappedDepth。
攻牙深度不超過底孔；螺距及所需牙深仍 unknown。

## Checkpoint、Demo、存檔

獨立 key `machine-lab.campaign.head.v1`，spec version `hammer-head-user-stock-v1`。
保存 currentLevel、completedLevels（只代表操作紀錄）、revisions、working、measurements。
下一關複製實際輸出；Retry 恢復本關開始 checkpoint。換銑床／鑽床只換 setup，不改工件資料。
reload 載入本關 working；需重新按開始裝夾，主軸不會自動啟動。
存檔格式錯誤顯示錯誤，不覆寫；與槌柄及自由加工存檔分開。

Demo 使用既有 DemoSequence/input lock/host clock，命令只走 MachineSession。
示範從本關 input clone 開始，不保存 Demo 工件。暫停／重播／跳過後恢復玩家實際工件。
試銑 0.5 mm、試鑽／攻牙 2 mm 是固定教學示範路徑，非圖面要求或實機加工建議。
M10 Demo 若 input 沒有有效底孔會明確拒絕，不能憑空新增底孔。
