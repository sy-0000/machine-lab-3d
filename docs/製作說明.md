# MACHINE LAB 製作說明

**MACHINE LAB｜工具機 3D 互動教學** 是一個網頁版教材，內容有工安守則、工具盒、車床／銑床／鑽床的 3D 加工教室，還有限時加工關卡。整個專案是我跟 AI（Claude）一起做的，以下照製作順序簡單介紹每個步驟。

> 使用技術：React + Vite + Three.js（React Three Fiber）、Canvas 2D

---

## 1. 排版：先決定風格

- 我先給 AI 幾個關鍵字（例如想要的氛圍、主題），請它提出幾種不同的風格選項。
- 從選項裡挑一個喜歡的，再往下細修。
- 小技巧：先定風格再做內容，後面每一頁看起來才會一致。

## 2. 模型拆零件：Sketchfab 找模型，AI 拆零件

- 到 [Sketchfab](https://sketchfab.com/) 找想要的 3D 模型（車床、銑床、鑽床），挑選 **Creative Commons 授權** 的模型。
- 請 AI 把整台機器拆成獨立零件（例如手輪、刀座、主軸、把手），這樣每個零件才能單獨轉動、移動。
- 模型太大時請 AI 壓縮，讓網頁載得動（例如銑床從 181 MB 壓到 15 MB）。
- 注意：要在網站上標示模型作者和授權出處。

## 3. 調參數儀表板：確認每個零件都能用

- 請 AI 做一個「調參數儀表板」，可以直接拉滑桿調整零件的位置、旋轉軸、移動範圍。
- 一個一個檢查零件，確認都能正確動作（轉的方向對、不會穿模、不會飛走）。
- 調好的數值存下來，之後正式網頁直接使用。

## 4. 建立世界：用 Three.js 做 3D 場景

- 3D 場景用 Three.js 製作，主要參考這支教學影片：
  <https://www.youtube.com/watch?v=gX4Qb2SffFM>
- 把拆好的機台放進場景，加上燈光、地板、攝影機視角，做成可以操作的「加工教室」。

## 5. 做細節：工安規則 + 關卡

- 把工安規則放進網站（工安守則頁、工具盒介紹）。
- 加上加工關卡：限時完成加工，依照尺寸誤差給 0～3 顆星，讓學習變成闖關。

## 6. 做動畫：用 Canvas 2D

- 用 Canvas 2D 做繪本風的原理動畫，說明機器是怎麼加工的：
  - 車床是怎麼切削的？
  - 銑床是怎麼切削的？
  - 鑽床是怎麼鑽孔的？
- 2D 動畫用來講「原理」，3D 教室用來「動手操作」，兩者互相搭配。

---

## 製作流程總覽

```
排版定風格 → 找模型＆拆零件 → 儀表板調參數 → Three.js 建立世界 → 工安規則＆關卡 → Canvas 2D 動畫
```

> 備註：這是教學模擬，機台的行程與進給不是實機校正數值，不能取代實機操作訓練。
