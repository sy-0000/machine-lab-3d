# 第三版驗證紀錄

日期：2026-09-18；Node.js 22.20、Windows、Chromium。測試使用真實 GLB 與實際頁面事件。

## 核心與建置

- npm test：22 / 22 通過。包含 13 項歷史車床回歸、6 項共用核心測試、3 項本版機械／材質測試。
- npm run audit:models：三台模型設定的節點缺少參照皆為 0。新銑床 manifest 的 422 個名稱均可找到。
- npm run build：完成；dist 已更新。共用 3D bundle 約 975 kB，Vite 有大型 chunk 提示，沒有建置錯誤。

## 新版驗證項目

1. 車床燈、圖紙架、黃色主軸護蓋不在展示場景中。
2. X、尾座位置、套筒下限分別為 -0.14、-0.278、-0.11，越界輸入會截限。
3. 外撥／內撥時，握桿球頭確實往操作者／機器內側移動，主軸正反向旋轉；停下保留角度，急停仍有效。
4. 左拉桿以實際幾何球頭與底座中心校正，四個位置的量測角度為 60、90、120、150 度；重設為 90 度。
5. 背面尾座位置手輪有獨立 Pivot，帶動尾座位置但不旋轉原套筒手輪。兩個新增手輪皆補有連接軸，避免懸空。
6. 銑床 UV、法線及 PBR 貼圖均保留；全部 1,445,428 面完成來源對照，最大頂點誤差 3.332e-8。
7. 銑床新增 Z 手輪正向轉動會升高工作臺；Head_Part_023 握桿與既有開關均可啟停，主軸箱保持固定。
8. 鑽床工作臺握把的 390 個三角形與表面細節同步升降，機頭與線材保持固定。

## 瀏覽器驗證

`npm run test:browser`：16 / 16 通過（Chromium，約 6.2 分鐘）。

測試包含桌面真實射線點選、右鍵反向、相機旋轉／縮放／平移、手機觸控取消、鑽床自動回位、控制行程、主軸與警告、重設、載入失敗與缺少節點報錯。

安全警告案例已適應新的 X 限制：無工件時驗證黃色進給警告；重設、裝上示範工件後，在 -0.14 驗證紅色接近警告。原先將工件一直裝著的測試會提早得到正確的紅警告，已修正測試操作順序，未降低警告條件。

開發測試的唯讀射線採樣增加角度／拉桿狀態快取鍵，並限制每次採樣數量，避免轉到背面尋找被遮擋零件時，測試工具拖慢頁面；正式版不載入此工具。

## 限制

- 未以實體手機或真實工具機驗證；導程、新增手輪尺寸、主軸桿功能為教學設定。
- 銑床後柱 Back_1019、1020、1021、1024 的原始底色圖缺失，目前使用相近漆色加原法線；已找到的 1018／1022 底色已嵌入 GLB。不能宣稱四張缺圖的鏽斑完全還原。
- 新銑床 GLB 約 190 MB；首次下載比第二版無貼圖模型慢。舊檔及一次性遷移工具放在 todelete，網站不依賴它們。
