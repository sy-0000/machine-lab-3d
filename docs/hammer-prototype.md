# 槌柄加工小關卡

入口：加工教室或關卡選擇頁的「槌柄加工小測試」，路由為 #/hammer-prototype。

## 操作

1. 觀看本關示範；返回練習會恢復示範前的工件與狀態。
2. 按座標歸零。這只改讀數零點，不會移動刀具。
3. 啟動主軸與進給；本原型固定切削深度與速度，到點自停。
4. 可停止進給、保持主軸轉動約 1.5 秒，觀察局部褐色環紋。暫停全部不累積刀痕。
5. 第一關完成後沿用工件進第二關。重試第二關仍保留第一關成果。
6. 通關成果存於本瀏覽器 localStorage：machine-lab.hammer-prototype.v1。第一關存檔可在重新整理後接續第二關。

## 資料與程式

- src/levels/hammerPrototype.js：固定毛胚、兩關尺寸、進給速度、純加工狀態計算與存檔驗證。
- src/pages/HammerPrototype.jsx：示範／練習狀態、歸零、暫停、重試、存檔、輪廓圖。
- src/components/HammerPrototypeScene.jsx：局部工件與刀具 3D 視圖。
- src/styles/hammer-prototype.css：試作頁面樣式。

所有輪廓與進給值以 mm 計；沿工件長度每 0.5 mm 儲存剩餘半徑。每次加工掃過整段移動區間，更新為新舊半徑的較小值。表面刀痕是獨立且有上限的視覺資料，不會讓材料無限變薄。

本版用簡化的局部加工視圖測試流程，沒有修改既有機台 runtime。完整車床的 X 為縱向、Y 為橫向、Z 為刀具高度，後續整合需以實際 JSON 與刀尖掛點校準，不可直接假定一般車床 X/Z 命名。局部視圖的刀具與切削接觸為教學抽象，尚未模擬刀刃寬度、受力、刀具進退路徑或真實切削參數。

本版尚不含自由調整切深、超差評分、切屑粒子、壓花、螺紋與槌頭加工。尺寸和速度都是流程測試值，並非加工圖面或實機作業參數。

## 驗證

- npm test：包含輪廓只減不增、定點停機、停留刀痕、工件繼承與存檔格式。
- npm run build
- npx playwright test tests/hammer-prototype.spec.js：示範副本、歸零、操作、重試、存檔接續、兩關尺寸、行動版與路由清理。

## 關卡與教室入口更新

關卡頁列出兩關的目標、直徑與進給量。「開始體驗」前往 #/experience/handle-grip 或 #/experience/handle-front；「觀看示範」使用對應的 #/demo/ 路徑。直接進第二關時，優先讀取第一關存檔，沒有時使用標準握柄。教室提供各關示範選擇，控制台將啟停、微調／手輪與工件分區；轉速設定與全部軸向滑桿可展開操作。
